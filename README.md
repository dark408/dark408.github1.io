# Victor Nwachuku — Portfolio Website

A responsive, premium dark-theme static portfolio built with HTML, CSS, and a small amount of JavaScript. No build tools or paid hosting are required.

## Files
- `index.html` — complete portfolio website.
- `README.md` — this guide.

## Before publishing
1. Confirm your education award title and dates.
2. Confirm the exact employers, job titles, and dates for each experience entry.
3. Replace project placeholders with real projects and links. Remove any entry that does not accurately describe your work.
4. Add a professional email address and, if desired, a reviewed CV PDF link.
5. Confirm your LinkedIn URL.
6. Review all text for accuracy and remove confidential client/employer information.

## Preview locally
Double-click `index.html` to open it in a browser.

## Publish with GitHub Pages
1. Sign in to GitHub and create a new public repository named `dark408.github.io`.
2. Upload `index.html` and `README.md` to the repository root.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/(root)`, then save.
5. Wait for deployment and open `https://dark408.github.io`.

GitHub Pages can take several minutes to publish. Its published site is public, so do not upload private information, confidential work, or personal documents you do not want public.

Official guide: https://docs.github.com/en/pages/quickstart
